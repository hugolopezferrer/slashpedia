# Sources and licence registry — Slashpedia

Every source is recorded here — name, link, licence **as verified**, and date checked — **before** any of its content is used (Step 0 of Slashpedia's content policy). If a licence cannot be verified, the source is treated as "no permission": name + our own description only, never its texts.

*Toda fuente queda registrada aquí — nombre, enlace, licencia **tal como fue verificada** y fecha de verificación — **antes** de usar cualquier contenido suyo (Paso 0 de la política de contenido de Slashpedia). Si una licencia no se puede verificar, la fuente se trata como «sin permiso»: solo nombre + descripción propia, nunca sus textos.*

**Deduplication rule:** one command = one entry. If the same command name appears in several sources, the version from a verified open-licence source wins (full prompt, with credit). Only when no open-licence source has it does the entry fall back to name + our own description.

***Regla de duplicados:** un comando = una sola entrada. Si el mismo nombre aparece en varias fuentes, gana la versión de la fuente con licencia abierta verificada (prompt completo, con crédito). Solo cuando ninguna fuente de licencia abierta lo tiene, la entrada queda en nombre + descripción propia.*

## How a new source is added

1. Open the source and find its licence (a `LICENSE` file, a licence notice, or its terms).
2. Record it in the tables above, with the date.
3. Only then may its content be used — and only as far as that licence allows.

*Cómo se agrega una fuente nueva: (1) abre la fuente y busca su licencia (un archivo `LICENSE`, un aviso de licencia o sus términos); (2) regístrala en las tablas de arriba, con la fecha; (3) solo entonces se puede usar su contenido — y solo hasta donde esa licencia lo permita.*
